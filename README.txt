AI DISASTER RESCUE PLANNER — MULTI-PAGE PORTAL

Pages: index.html (Dashboard), flood-history.html, risk-assessment.html, rescue-routes.html, resources.html, about.html. Shared CSS/JavaScript are in assets/.

RUN: Extract ZIP, open the whole folder in VS Code, open index.html, then use Live Server or double-click index.html in File Explorer. Use the top navigation to switch pages.

PUBLISH: Upload all files and folders to the root of a GitHub repository. Settings > Pages > Deploy from a branch > main > /(root) > Save.

LIMITATIONS: This is an educational prototype. Risk scoring is rule-based, not a trained ML model. Route options are illustrative and not connected to live maps, GPS, road closures, weather, or emergency authorities. Verify historical data against official reports. Do not use for real emergency decisions.
